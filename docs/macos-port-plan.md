# Yoho Music macOS 移植计划

用 Go 和 NSGo 移植 MyGo Music `v0.1.25` 的 macOS 应用。交付时对齐原版的可见界面、动效、键鼠交互、功能和 macOS 系统行为。以原版正式发行包做实机对照，以同一提交的源码和测试解释细节。 [MyGo Music v0.1.25 发行说明](https://github.com/egoist/mygo-music/releases/tag/v0.1.25)

## 模块和技术选型

| 模块 | 实施方式 |
| --- | --- |
| 应用与界面 | 用 `nsgo.Run`、`core`、`desktop` 和 `nsgo.yaml` 搭建应用、窗口和发行流程。按 `internal/app/ui_*.go` 顺序迁移页面和状态，将原版颜色、字号、尺寸、布局与交互映射为 NSGo 样式、signal 与虚拟列表。歌词舞台、封面墙、黑胶和磁带的自绘部分用 NSGo Canvas 测试，按实测补充着色器与平台适配。自绘部分同时验证命中区域、键盘焦点与无障碍。 |
| 播放与设备 | 先保留原版队列、解码、缓存、淡入淡出和响度逻辑，候选输出先使用 MyGo 的独立 `audio` 包验证。播放模块统一接收主窗口、菜单栏和系统媒体命令，发布同一份曲目与进度状态。macOS 媒体命令通过 MediaPlayer 接入，并由应用作用域持有播放器。 |
| 本地曲库 | 优先移植 `internal/music`、`internal/local`、`internal/lyrics`、`internal/i18n` 和原版用例。沿用 JSON 模型、曲目标识、封面缓存和恢复顺序。使用测试曲库对照扫描、文件变更、LRC 时间轴和歌单。 |
| 插件和播客 | 以 MyGo Music 的音源能力组织方式为参考，使用 NSGo 签名包和 `tsx.Load` 实现 Yoho 的插件宿主。用 Yoho 示例覆盖搜索、播放和登录，按插件声明约束网络和凭据访问。移植 `internal/speech` 与字幕状态，核对 Sherpa-ONNX 库、Qwen3-ASR 模型的获取及运行条件。 |
| macOS 集成 | 用 `desktop.OpenPanel`、`desktop.NewTray` 和窗口生命周期接口验证托盘及浮层。刘海位置、显示器切换等通过 AppKit 适配器补齐。另测单实例、链接唤起、快捷键、睡眠唤醒、应用退出与签名包。 |

NSGo `v0.2.0` 用于界面验证。该标签公开了音频接口和测试替身，平台长音频后端仍待交付。优先比较原版音频包的独立运行效果。若项目要求移除所有 `github.com/egoist/mygo/*` 依赖，则在音频接口处切换到支持 PCM 输出的固定 NSGo 提交，或接入 macOS 原生音频，按原版格式与处理行为重新验收。以实测结果固定最终依赖版本。 [原版音频接入](../references/mygo-music-0.1.25/internal/player/player.go) · [NSGo v0.2.0 路线图](../references/nsgo-0.2.0/docs/roadmap.md) · [NSGo main PCM 接口](https://github.com/nsgo-dev/nsgo/blob/main/audio/output.go)

## 实施顺序与阶段成果

| 阶段 | 工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| 1. 建立对照基准 | 打开原版发行包，记录默认窗口和最窄支持尺寸、亮暗主题、简中与英文。生成或捕捉首页空状态、歌单、播放页、设置、歌词舞台、封面墙、黑胶、磁带和刘海的标准截图及交互短片。上游 `MM_FRAMES` 测试用于补充关键帧。 | 有可重复使用的测试内容、状态和操作清单，每项都有原版截图、录屏或可观察结果。 |
| 2. 验证 NSGo 和关键风险 | 用 `go tool nsgo doctor` 和 `dev` 跑起 Go 应用。实现一个贯穿主窗口和菜单栏的验证切片，涵盖真实出声、暂停、跳转、下一首、关闭主窗口继续播放、系统媒体键，并对照验证一个歌词舞台片段和一个透明刘海面板。 | 确定框架版本、绘制路径和音频输出路径。对照记录鼠标穿透、刘海与无刘海设备、外接屏和全屏表现。 |
| 3. 移植本地曲库、普通页面和播放 | 完成首页、侧栏、搜索、专辑、艺人、收藏、歌单、设置和底栏。迁移目录扫描、原版格式、队列、洗牌、循环、音量、来源切换、会话恢复及异常状态。 | 用同一测试曲库对照原版操作，核对搜索、排序、曲目信息和播放结果。以同一尺寸和主题验证普通页面。 |
| 4. 完成自绘和系统集成 | 对齐播放页展开与收起、歌词同步及样式、封面墙、黑胶及磁带、拖拽弹性、刘海、菜单栏、热键和窗口生命周期。 | 比对静态画面与动效关键帧，在真实窗口验证滚动、悬停、点击、触控板和系统控制。 |
| 5. 完成在线能力及播客 | 实现 Yoho 插件的安装、更新、权限、设置、账号、目录、远程控制、网络缓冲、缓存、播客与实时字幕。 | 通过 Yoho 示例插件和可控媒体样本验证完整链路。验证断网、权限拒绝、定位、缓存淘汰、退出重启和字幕模型获取。 |
| 6. 整体验收与发行 | 跑 Go 行为测试、`nsgotest` 和真机专项。以实际应用包验证两个发布架构、签名、公证和更新。 | 对照清单逐项通过。可复现的视觉或行为差异有记录、复测结果和发布结论。 |

## 对齐标准

- **静态界面**在相同 macOS 版本、显示缩放、窗口尺寸、语言、主题与页面状态下对照。检查字重、间距、图标、截断、背景、阴影、选中、焦点、空状态及错误状态。用截图叠图定位差异，每处差异进入对应页面的验收记录。
- **动效与交互**用相同点击、拖拽、滚动和键盘操作验证起点、关键帧、结束状态、操作中断及反向操作。覆盖歌词舞台、黑胶、磁带、封面墙和刘海动画，并使用上游空闲帧率相关用例作为性能对照。 [原版截图用例](../references/mygo-music-0.1.25/internal/app/frames_test.go) · [原版性能用例](../references/mygo-music-0.1.25/internal/app/perf_test.go)
- **音频**用相同曲目验证 MP3、FLAC、Ogg Vorbis、WAV、AAC 及 M4A 中的 ALAC、FLAC、AAC。对照暂停、定位、缓冲、结束自动切歌、响度、淡入淡出和会话恢复。用可控来源覆盖鉴权头、慢流、远程播放和缓存。
- **验收记录**每项记录原版截图或操作、Yoho Music 对照结果和适用环境。参考截图和测试对应同一个固定版本，UI 与系统专项测试对应实际打包产物。 [NSGo 测试文档](https://nsgo.dev/zh/docs/testing/) · [NSGo 构建与发布](https://nsgo.dev/zh/docs/building/)
